# MET association and term reconstruction

Use the installed `METMaker` as the reference for the fixed PFlow Tight, NNJVT, muon-jet EM-scale and `PVSoftTrk` recipe. The installed `ColumnarMETMaker` provides an extraction guide for the association and arithmetic loops. Its array entry hits xAOD-only calls on active branches and its weight-column output omits information required by significance. This review is based on source inspection of AnalysisBase 25.2.117 at Athena `6ce3f7ae7c41dd9eaec170c3c349df15faef7e5c`. The production-file link inventory and numerical parity are separate acceptance checks. [Campaign contract](contract.json) · [Release source manifest](source-manifest.json)

`ElementLink` stores unsigned `m_persKey` and `m_persIndex`. The key identifies the target container through its StoreGate name and CLID. Use input file metadata and the appropriate link type to resolve the owner, then range-check the event-local index against that owner. The release uproot decoder documents both split fields and nested records. It recognizes `(key,index)=(0,0)` and `index=UINT32_MAX` null encodings. Its single-target path checks the index against target offsets and leaves key validation to the caller. In particular, `objectLinks` is polymorphic. Keep unresolved and null links distinguishable in the audit and retain their association-local positions. [Link layout][persist] · [Link-key and uproot decoding][decode]

The published PHYSLITE derivation config sets up the AOD association directly on the `Analysis*` owners and delegates PHYS input to remapping. Its slimming list retains the AnalysisMET association and core and omits `originalObjectLink` from the hard-object auxiliary leaves. Treat this as a cross-check of the intended persisted layout. Confirm the p7266 file's actual branch inventory, per-key owners and null shapes independently. In the analysis job, CP original-link decoration connects copies to their base xAOD objects, or propagates an existing original link when copying an already-linked container. `METMaker` decides whether its nonempty input is original from the first row's decoration. It skips a shallow hard-object input that lacks that decoration and writes each accepted constituent link using the current object's owning collection and index, including when the input is a view. Carry the two identities separately in B and C. ## Reusable source and parity gaps

- **Hard-object selection and association reductions.** Reuse the ordered hard-object skeleton from `ColumnarMETMaker` and extract the `MetAssociation` mask and reduction bodies over typed original keys. All containing associations participate in PFlow overlap removal. Selecting a non-overlapping object sets flags in all its associations. An object already flagged in any association is skipped. Muons have `removeOverlap=false`, but the select-and-flag call still runs first, and CaloTagged muons have the additional selected-electron veto. Preserve the reference's missing-electron zero-weight link and missing non-electron fallthrough. For ordinary jet associations, sum keyed vectors that intersect the selected mask. The miscellaneous association uses the inverse predicate and the last `isMisc` row. The stock code resets flags for each state. [Reference selection](source/METMaker.cxx#L270-L445) · [Columnar skeleton](source/ColumnarMETMaker.cxx#L300-L438) · [Reference composition][composition] · [Columnar selection and lookup][helpers] · [Columnar mask reductions][reduce]
- **Jet and TST arithmetic.** Extract the constituent-scale denominator choice, scale and subtraction, high-pT electron residual-track exception, muon-jet removal and `MuonEloss` logic, hard-jet weighting, and rejected-jet and miscellaneous soft-track reductions. Keep source operation order, constituent-vector precision, per-add float storage and the actual JVT assignment. Both makers overwrite the initial maximum-eta rejection with the JVT tool decision when enabled. A jet rejected by JVT can still add its residual track vector to TST subject to the soft region test. The muon FSR branch adds to `MuonEloss` and skips subsequent jet/soft link emission. The columnar arithmetic template supplies useful source bodies once xAOD reads are replaced with explicit inputs. [Reference jet decision](source/METMaker.cxx#L689-L758) · [Columnar constituent and jet arithmetic](source/ColumnarMETMaker.cxx#L730-L775) · [Columnar electron/muon arithmetic](source/ColumnarMETMaker.cxx#L805-L1004) · [Columnar TST and miscellaneous reductions](source/ColumnarMETMaker.cxx#L1032-L1103) · [Float momentum casts][inputmom] · [Float accumulation][accum]
- **Array entry gaps.** `getXAODObject()` throws in array mode. JVT calls it on the jet, the selected-electron track-vector calculation calls it on the electron, and the muon loop uses it for energy loss, ID-track access and energy-loss type. The PV lookup is an xAOD read handle. The optional nominal-copy, greedy-photon, ghost and soft-constituent paths have further xAOD access, so avoid pulling them into the fixed recipe when inactive. The array `OriginalObjectHandle` returns the current ID. Association `objectLinks` is declared as a variant whose target list has no `TauDef`, and the installed Python bridge rejects variant columns. These are concrete limits on reusing the stock array entry and bridge. Also probe muon slot indices at and above 31 in synthetic tests. The stock source shifts an `int` in its muon calorimeter mask. ColumnarMETMaker shifts the 64-bit mask type. Establish actual inputs and release behavior before choosing high-slot handling. [Array object guard][getxaod] · [Array identity behavior][arrayorig] · [Supported variant declarations][assocfields] · [Bridge rejection][variant] · [Active xAOD calls](source/ColumnarMETMaker.cxx#L739-L741) · [Electron and muon calls](source/ColumnarMETMaker.cxx#L833-L934) · [Stock muon mask](source/METMaker.cxx#L902-L914)
- **Significance and link parity.** Significance skips invisible and total terms and consumes the TST term as a vector with `sumet`. For hard terms it dereferences ordered `ConstitObjectLinks` and uses the current object's momentum and resolution. This loop never reads `ConstitObjectWeights`, so a linked missing electron can affect significance even with weight zero, and a weighted jet reaches significance through its calibrated jet object. xAOD hard-term handles record links and optional weights. The array handle uses a zero-initialized per-object weight column, collapsing present-with-zero and absent. The per-object layout also omits term-local ordering. Stock `METMaker` writes TST soft-jet links and builds `softJetWeights` locally without publishing a TST weight decoration. The separate `softConst` collection is optional and PFlow suppresses its track-fill branches. [Significance consumer](source/METSignificance.cxx#L247-L330) · [Reference soft-jet links and optional track constituents](source/METMaker.cxx#L1025-L1079) · [xAOD and array output handles][weights]

## First shared node and test vectors

Use one registered native MET-maker node with an event input containing typed, offset-based association rows, the core-term fields and the nominal object rows. B translates xAOD owners and current links into stable IDs and materializes the returned xAOD terms and links. C resolves identities and prepares offsets from the original input and obtains the nominal objects and selections from the independently reproduced upstream calculations. The node owns flag resetting, overlap policy, constituent-scale arithmetic, jet decisions and term filling. Its payload fixes the working point, object pass order, source masks, enabled branches and cut/systematic dependencies. Return ordered term records with storage-precision `mpx/mpy/sumet`, status and a term-local ledger of current constituent IDs and weights where emitted. Keep original identities, flag masks and decisions in a diagnostic result. Invoke the same NNJVT implementation through CorrectionLib, binding the actual initialized code and decision inputs before adopting any earlier jet artifact. Then feed the rebuilt terms to the soft correction and Final sum and pass the constituent ledger to significance. Treat ragged native input/output as a provider interface to verify against the pinned CorrectionLib API. [Graph design guidance](https://github.com/gordonwatts/atlas-cp-speed-jets/blob/cd1fd0628f3c5d68287ca1dc80ae593d8533b06c/.agents/skills/convert-calibrations-to-correctionlib/references/graph-design.md) · [Reference caller sequence](source/MetMakerAlg.cxx#L127-L206) · [Final sum](source/METHelpers.cxx#L90-L112)

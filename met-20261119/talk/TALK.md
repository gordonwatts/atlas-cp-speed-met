# Rebuilding Missing Transverse Momentum From PHYSLITE

Gordon Watts, ATLAS software and calibration working group. Allow 15–18 minutes for the main talk. For a 12-minute slot, use the standalone agreement plot, the input-cost plot, the empty-link and chunk-size comparisons, then the final timing and demo. The [editable PowerPoint](MET.pptx) contains speaker notes. The [report](../report.md) gives the full analysis and runnable script.

# MET optimization experiments

The faithful implementation follows the stock tool boundaries. The initial shortlist below records which ideas reached a measured comparison. The sections that follow give the controls, decisions and unchanged physics for each executed trial. The [initial MET register](../met/optimization-ideas.md) also records storage reuse, multiple outputs, native batches and earlier unsuccessful reader experiments.

## Call counts from the stock job

The independent trace supplies an upper bound on repeated work in the five-state job. These counts precede the faithful B/C timing. They establish how many calls a proposed change could remove. Elapsed time depends on the cost of the reached calls and the cost of preserving their observable results. [Stock trace](evidence/reference/status/full-verification.json) · [Constituents and state inventory](evidence/reference/full/summary.json)

| Operation across 20,000 events | Observed or derived in five states | Opportunities to test |
| --- | ---: | --- |
| Hard-object rebuilds | 400,000 calls | Reusing the four nominal hard terms would remove 320,000 calls if all flags, statuses and links can be reproduced. |
| Per-jet MET JVT decisions | 983,030 calls | Reuse once per jet could remove 786,424 decisions. METMaker accepted 191,779 of the 196,606 JVT decisions per state. Other MET jet cuts still apply. |
| Association flag writes | 64,575 calls | A single verified reconstruction could avoid 51,660 writes while retaining the immutable nominal contributor lists. |
| Gaussian draws | 80,000 calls | Nominal drew none. All four recommended variations drew once per event from the same reset seed. A shared draw would replace up to 60,000 calls if the public return values and later observable stream state agree. |
| Hard constituent entries across the five states | 560,560 entries from the five nominal hard-term counts × five | Cacheable nominal object resolutions could avoid up to 448,448 evaluations if ordered membership is identical. Each state's covariance rotation still needs its own Final direction. |

The original NNJVT updater passed 176,786 jets. METMaker's JVT check accepted 191,779. They serve different callers and have different eligibility rules. Keep distinct counters in the converted provider. [Updater and maker inputs](evidence/reference/full/summary.json) · [MET JVT decisions](evidence/reference/status/full-verification.json)

The independent five-state comparison establishes which results can be shared in an optimization trial. On every event, the four non-nominal runs reproduced the nominal electron, photon, tau, muon, muon energy-loss and jet terms. Their ordered links and weights, association writes and jet decisions also matched nominal. All four active variations used the same seed and first Gaussian per event. The frozen framework replacement reproduced those same stock decisions and observables. The first direct-runtime trial can build the unvaried terms and ledger once per event and evaluate all four variations from that immutable input. Time the complete file-to-file workflow and verify each state, including order and statuses, before retaining the change. [State-by-state invariants](evidence/components/framework-frozen/invariants.json)

Final significance still needs work in each state. It changed in 19,689 events for scale down and 19,690 for each other recommended variation. Each of the 100,000 valid state rows had a track soft term contributing the configured nonzero resolution. The stock exceptional zero-longitudinal-variance path can retain an earlier squared significance. A trial can cache the nominal object resolutions, but it must still rotate into each varied Final direction and keep the release's ordered state transitions for the exceptional cases. [Invariant and response counts](evidence/components/framework-frozen/invariants.json) · [Reducer](inspection/components/significance/reduction.cxx)

## Faithful standalone baseline

The installed faithful package at WSL `6b19c47` took 4.022 ± 0.056 s for all five states, 3.714 ± 0.068 s for nominal and 0.465 ± 0.016 s for the separate stored control. Each total passed the predeclared timing screens. The full and nominal framework replacement totals also passed. A bounded matched repeat qualified the full workflow for all three paths. Its framework B/A ratio was 1.00368 and its end-to-end A/C ratio was 5.48258. [Bounded repeat](evidence/timing/matched-repeat/summary.json) M02 is the first structural trial. Its potential savings are bounded by the cost of repeated reconstruction in the full native event loop. [Matched means, spreads and all repetitions](evidence/timing/matched-faithful/summary.json)

## Reusing the hard terms across systematic states

M02 reduced actual maker calls from 100,000 to 20,000. The other 80,000 state results used the first calculation for the event. The independent full, nominal and correlated comparisons all agreed with stock, including ordered links, decisions and the live inputs to significance. The Linux wheel reproduced the saved histograms. [One-change patch](evidence/timing/m02/M02-maker-reuse.patch) · [Full comparison](evidence/timing/m02/full-acceptance.json) · [Separate correlated check](evidence/timing/m02/corr-acceptance.json)

| Matched C runs | Faithful full (s) | Reuse full (s) | Change in mean elapsed | Nominal control |
| --- | ---: | ---: | ---: | --- |
| Initial series | 4.152 ± 0.085 | 4.062 ± 0.075 | 2.19% faster | 2.90% faster despite the same number of maker calls |
| Independent series with control and candidate order reversed | 3.967 ± 0.037 | 3.936 ± 0.044 | 0.78% faster | 0.38% faster |

Both full timing cohorts passed. In the reversed series the three paired savings were −17, +67 and +44 ms. That spread includes improvements smaller than the 0.5% threshold. The faithful build was restored for subsequent trials. This result preserves the numerical proof and the observed call reduction. It leaves the full-workflow benefit unresolved. ## Repeated empty link projections

The accepted M21 change keeps the first type and shape validation and skips subsequent empty projections for the same input within a chunk. With unchanged native libraries, full C fell from 3.935 ± 0.013 s to 3.316 ± 0.033 s. The three paired savings were 636, 596 and 626 ms. Nominal also improved by 17.48%. Full, nominal and correlated runs all agreed with stock. [Timing and RSS](evidence/timing/m21/summary.json) · [Independent comparison](evidence/timing/m21/full-acceptance.json) · [Changed code and tests](evidence/timing/m21/M21-empty-projections.patch)

## Conditional jet sampling data

M22 reads `EnergyPerSampling` only when the maker needs the fallback for a missing `PSFrac`. The 20,000-event projection now reads 17,901 baskets and 69,739,982 compressed bytes. The full matched workflow improved by 2.27% (3.330 ± 0.022 to 3.255 ± 0.037 s), with positive savings in all pairs and lower peak memory. Both nominal cohorts failed spread screens. Retained after the three original-reference checks and fallback fixtures passed. [Measured projection](evidence/timing/m22/full-logical-root-requests.json) · [Matched benchmark](evidence/timing/m22/summary.json)

## Events per chunk

The same M22 wheel at 5,000 instead of 2,000 events per chunk reduced the five-state time by 14.30% (3.278 ± 0.023 to 2.809 ± 0.027 s), while the peak retained resident set increased by 40 MiB. Nominal also qualified. The 5,001-entry and empty tests preserved the outputs, and all full, nominal and correlated checks passed. This result justified one further fixed-size trial at 10,000. [Timing, counts and memory](evidence/timing/m23/summary.json) · [Full comparison](evidence/timing/m23/full-acceptance.json)

In the independent 5,000-versus-10,000 comparison the five-state mean went from 2.788 to 2.794 s and peak RSS from 482,092 to 556,612 KiB. Nominal was also slightly slower. We retained the fixed default of 5,000 entries. [Recorded paired runs](evidence/timing/m23/five-to-ten-thousand.json)

## Indexing the tree's branch names

M25 replaced 203 independent existence tests, including 37 cold misses requiring a recursive traversal, with a single ordered projection against a set of the tree's exact branch names. Full C went from 2.776 ± 0.012 to 2.684 ± 0.008 s (3.33%); nominal improved by 3.72%. Both cohorts passed and the original field order, missing-field list and stock event observables matched. [Source and fixtures](evidence/timing/m25/M25-exact-recursive-branch-names.patch) · [Paired timing](evidence/timing/m25/summary.json)

## Grouping ordinary MET association reads

A single uproot request for 21 ordinary association siblings produced the same nested arrays, ROOT link keys, indices and packed buffers as the 21 direct reads. The special memberwise jet-link decoder remained separate. Five full passes gave 0.230 s of CPU time in the original read path and 0.231 s with grouped reads. The work still visited the same original basket extents. This reader experiment supplied no saving to carry into a production timing cohort, and the direct reader was kept. [Measured raw projection](evidence/timing/m19/raw-projection.json) · [Basket-boundary and schema tests](evidence/timing/m19/unit.log)

## Event-local first Gaussian

Standalone C reused an exactly identical first Gaussian 60,000 times across 80,000 logical active draws. Each new event starts with a fresh cache and any new seed computes an independent first value. The full matched mean fell from 2.717 ± 0.048 to 2.657 ± 0.029 s (2.20%). Nominal made zero draws and had a 1.37% higher mean, with large paired scatter. The single active state in the separate correlated run exercised 20,000 physical draws and zero hits. Retained for five states. [Draw comparison](evidence/timing/m03/full-draws.json) · [Timing](evidence/timing/m03/summary.json)

The M26 adapter uses a typed view on aligned contiguous scalar fields and keeps the general path for other layouts. Full elapsed fell from 2.578 ± 0.015 to 2.531 ± 0.025 s (1.84%). ## Validating jet track offsets once per chunk

The 5,000-event native profile attributed 7.62% of sampled CPU to offset construction. M27 moved the checked track-count view to first use in each nonempty chunk. On the four original chunks this changes 20,000 whole-array scans to four. The retained primary full mean fell from 2.684 ± 0.099 s to 2.488 ± 0.115 s (7.28%) and all three pairs improved. The reverse-order full candidate exceeded both spread limits. Nominal qualified in both orders. Full, nominal and correlated stock comparisons and the malformed input checks passed.

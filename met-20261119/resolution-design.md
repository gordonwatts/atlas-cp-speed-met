## Framework boundary

The stock sequence corrects the soft term, builds `Final`, then calls significance on each state's container. `MetSignificanceAlg` passes average interactions per crossing and the names `RefJet`, `PVSoftTrk`, and `Final`. The MET block sets `SoftTermParam=0` (Random) and `TreatPUJets=false`. The remaining significance defaults are `SoftTermReso=8.5` GeV, no phi term, no bias, no extra jet/electron/muon resolution decorations, and no extra jet pT or eta limits. Tight JVT changes MET jet membership. Average pileup, Jvt and fJvt have corresponding inputs in the optional significance pileup-jet branch. The stock initializer still opens `METUtilities/data17_13TeV/metsig_Aug15/jet_unc.root` with phi resolution disabled. Preserve framework setup failure semantics and export event-time data for the resolved branches. [MET config](source/MetAnalysisConfig.py#L192-L244), [algorithm calls](source/MetMakerAlg.cxx#L175-L214), [Final builder](source/MetBuilderAlg.cxx#L38-L55), [significance algorithm](source/MetSignificanceAlg.cxx#L39-L72), [tool defaults and initialization](source/METSignificance.cxx#L85-L190), [term-name defaults](https://gitlab.cern.ch/atlas/athena/-/blob/6ce3f7ae7c41dd9eaec170c3c349df15faef7e5c/PhysicsAnalysis/Algorithms/MetAnalysisAlgorithms/MetAnalysisAlgorithms/MetSignificanceAlg.h#L53-63).

Process the MET term and link order. Skip total and invisible sources and take the first track-soft term with the requested name. Its isotropic covariance uses the configured variance and still runs the source rotation. For each other term use `ConstitObjectLinks` and the linked object's full pT and p4 direction. `ConstitObjectWeights` is absent from the significance calculation. For example, METMaker records a zero-weight linked missing-map electron and weighted hard jets. Soft-term links are bypassed by the soft branch. Preserve the float cast of each relative resolution and its float square before the double pT and GeV operations. Rotate the object covariance in the current state's MET direction, and accumulate the longitudinal, transverse and off-diagonal terms in source order. The local lab-frame matrix is written and never read by the default significance result. Nominal object resolutions may be shared across states whose identities and inputs match. The angle-dependent contributions and final significance use the varied MET vector. [Constituent traversal and covariance](source/METSignificance.cxx#L203-L381), [linked electrons](source/METMaker.cxx#L363-L380), [linked jets](source/METMaker.cxx#L988-L1007), [soft term](source/METSignificance.cxx#L618-L647), [rotation](source/METSignificance.cxx#L1023-L1040).

The squared result uses `MET² / (VarL * (1 − rho²))` with zero scalar bias, or `MET² / VarL` at `abs(rho) >= 0.9`. The accessor returns the square root for a positive squared result and `-1` otherwise. If enabled in the reference, the extra outputs use `MET/sqrt(VarL)`, `MET/sqrt(sumET)`, and `MET/sqrt(sumET − softSumET)` on their positive denominators. Missing `Final` fails at algorithm entry. Direct tool calls with an absent or wrong-source total return success early. Zero longitudinal variance leaves the previous squared significance and rho intact because those members are not reset at entry. A null constituent fails, a missing decoration follows accessor behavior, and a duplicate eligible track-soft term logs a configuration error and skips it. Test these stateful cases in call order and compare float decorations, sentinel and nonfinite classifications as well as success/failure. [Algorithm outputs](source/MetSignificanceAlg.cxx#L44-L69), [tool branches](source/METSignificance.cxx#L203-L381), [rho guard](source/METSignificance.cxx#L981-L995), [public getters](https://gitlab.cern.ch/atlas/athena/-/blob/6ce3f7ae7c41dd9eaec170c3c349df15faef7e5c/Reconstruction/MET/METUtilities/METUtilities/METSignificance.h#L75-83).

## Discriminating stock comparisons

The intake branch preview shows the four tau resolution auxiliaries and the egamma/muon link columns. Check full availability and target identity against release xAOD for clustered electrons/photons and the three muon track links, including event-local index, key, entry shape, missing links and resolved target columns. Photon vertex count should survive invalid or thinned conversion targets when the stock link vector stays nonempty. Verify exact ordering and full pT on linked objects whose MET weights differ from one. Require end-to-end event input from the original file for C. With a genuinely missing value, identify the source branch and affected linked population before deciding whether the stock fallback can be reproduced.
